## 1. ひとことで言うと

- **生産計画を入力し、製造管理の入庫予定に反映する** システム。画面 19、プログラム約 4,800 行。
- 計画（共有Accessテーブル.accdb の「大阪丸北生産計画」）を、製造カレンダーと計画入力の画面で入れる。
- 「取り込み」を押すと、前回の計画と比べて **新規・製造変更・kg 変更・包装日変更** を見つけ、製造管理の入庫予定を作り直し、WorkStation の出荷に「計画変更」の印を付ける。
- 販盛（販売管理）用の計画の Excel も作る。

## 2. つながり

| 相手 | 表 | 使い方 |

## 3. 画面と流れ

| 画面 | 内容 |
|---|---|
| **製造カレンダー** | 月のカレンダーに、日ごとの計画（商品・kg）を表示。工場を選ぶ（丸北北海道 11／ふらの 191）。日をダブルクリックで計画入力へ。祝日・会社休日も表示 |
| **製造計画入力** | 製造日・工場・作業場（1工場／2工場／ふらの）・商品・ケース（または kg）を入れる。商品名・規格・入数・賞味期限を自動で入れる |
| **メニューの「取り込み」** | 期間を選んで取り込む（下の流れ）。新しい計画があると、開いたときに知らせる |
| **変更案内** | 取り込みで見つかった新規・変更の一覧（WorkStation でも見る） |
| **計画変更ログ** | 取り込みごとの件数の記録（2026年2月から） |
| **販盛用の計画** | OneDrive の Excel の計画を読み、販盛の商品コードに置き換えて Excel に出す（販盛への取り込みは手作業） |

### 取り込みの流れ（中心の処理）
1. 製造管理の **未来の・まだ確定していない入庫予定** を、計画ごと（製造ID）に合計して「前回」として写す。
2. 選んだ期間の計画を「新規生産計画」に写す（全部入れ替え）。
3. 製造ID で前回と比べ、新規・製造変更（削除を含む）・kg 変更・包装日変更の印を付ける（今日の分は変えない）。
4. 変更のあった未確定の入庫予定を **削除** し、WorkStation の出荷に「訂正／計画変更」の印を付ける。
5. 新しい計画を **区分（タグ①②…）に分割** して入庫予定に追加し直す。
   - 分割の決まり：商品 × 作業場ごとのマスタ（1 区分の上限 kg、「残り全部」の印）で、上限ごとに区切る。2工場だけの日はタグを①から振り直す。
6. 変更案内・ログを作る。

- **確定済み・取り込み済み・手入力の行は守られる**。それ以外の未来の予定は「計画が正」で、手直ししても作り直される。
- 入庫予定を作り直すと番号（入庫ID）が変わるので、WorkStation 側で在庫の引き当てをやり直す必要がある。

### その他
- 包装日＝製造日の翌日（日曜なら月曜）。賞味期限＝製造日＋品質保持期間（年）＋日付差。
- 資材（段ボールなど）の自動発注の予測：2025年7月に 1 回動いただけで止まっている。計算も意味をなしていない。

## 4. 見つかった不具合・気になる点

1. **変更案内の表を作るときに列がずれる**（実データで確認：製造識別コードが管理備考に入り、「新規」の印が抜けている）。WorkStation の案内画面に影響している。
2. ログの合計に、包装日の変更が入っていない。
3. 確定済みの行があると、新しい計画の分割行も追加され、二重になるおそれ。
4. 取り込み期間を狭くすると、期間外の未来の予定に「削除」の印だけが残る。
5. 取り込みは確認なしで最後まで進む。2 人が同時に取り込むと壊れる（排他の仕組みがない）。
6. 週の予定表の画面（使われていない）に、**関係ない計画を消してしまう** 削除ボタンがある。
7. カレンダーが 5 週分しかなく、6 週にまたがる月の最後が出ない。決まった日付の祝日と振替休日が表示されない。祝日は 2025 年までしか登録されていない。
8. 計画入力の「編集」ボタンが、条件の書き方の誤りで 0 件になる。
9. 販盛用の出力で、えんゆう野菜加工施設・遠軽食品のコードを置き換えていない。
10. Excel（OneDrive）と Access の 2 か所で計画を別々に持っている。

## 5. Web 化のときに考えること

- 計画 → 照合 → 4 種類の通知 → 入庫予定の作り直し → 出荷に計画変更の印、の流れはそのまま再現する（守る行の条件も含めて）。
- 「取り込み」ボタンをやめて、計画を保存したときに差分を反映する方式にするかを決める。
- 入庫予定を作り直しても番号が変わらない作りにできれば、WorkStation 側の引き当てのやり直しが減る。
- Excel の計画と Access の計画を 1 つにまとめる。
- 資材の自動発注は、作り直すかやめるかを決める。
