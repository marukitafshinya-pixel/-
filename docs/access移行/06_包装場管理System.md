# 包装場管理System（Access）調査報告

- 全体像：[00_全体像.md](00_全体像.md)
- 調べたファイル：`包装場管理System FE.accdb`（画面側のファイル）
- この報告には、パスワード・サーバーの場所・PC 名・個人名を書かない。

---

## 1. ひとことで言うと

- **包装場（丸北北海道 工場 11）の毎日の作業** を支えるシステム。画面 32、帳票 81、プログラム約 10,200 行。
- 1 日の主な流れ：**包装準備（パレタイザーのプログラム割り付け）→ 包装札の印刷 → 帳票の印刷 → 生産計画予定表**。
- 元のデータは製造管理の入庫（TD_入庫）。検査の結果は WorkStation の在庫を直接書き換える。

## 2. つながり

| 相手 | 表 | 使い方 |
|---|---|---|
| 製造管理 丸北.accdb | 入庫 | 包装の元データ。ロボットのプログラム番号・管理備考・選択の印を書き込む |
| 包装場管理System.accdb（自分のデータ） | ロボット設定（入庫ごと）、ロボット積み付けマスタ、予定 | |
| 丸北WorkStation.accdb | 在庫、出荷、輸送計画 | 検査結果（商品区分）を書き込む・変更の知らせ・積込札・出荷開始時間 |
| 倉庫管理System.accdb | 出庫、輸送計画 | 使っていない帳票だけが参照 |
| 共有Accessテーブル.accdb | 新規生産計画 | 使っていない帳票だけが参照 |

## 3. 使われている機能

| 機能 | 内容 |
|---|---|
| **包装準備** | その日の包装について、パレタイザー（ロボット）のプログラムを選ぶ。パレット枚数＝ケース ÷ 積み付け数（切り上げ）。「自動割付」は過去の設定から選ぶ（ニチレイ大谷地行きは専用パレット (N)） |
| **包装札** | **1 パレット 1 枚** の札を作って印刷。在庫札、出荷停止在庫報告、大谷地回送用札、仕掛原料管理札（ソテー／ペースト）、包装連絡表（ロボット確認） |
| **帳票印刷** | 包装数量チェック表、包装日誌、HB ミックスセット日誌、積込札、製造計画分割予定表 |
| **生産計画予定表** | 45 日分。段ボール在庫・ラベル・パレット数・当日出荷・大谷地行き数、**包装予定時間＝ケース × 1 ケースあたりの秒数の平均**、出勤時間・予定 |
| **包装時間の登録** | 実際の包装時間を記録し、1 ケースあたりの秒数の標準にする（全履歴の平均） |
| **ふらのパレット確認表** | ふらの工場の大谷地行き・十勝行きのパレット数 |
| **予定表・カレンダー** | 包装場の予定・指示・欠勤・出勤時間。月カレンダー（予定／入荷予定／製造予定） |
| **週間包装スケジュール** | 人員 × 日の表を CSV に出す |
| **Google カレンダー** | 予定を CSV にして、人が Google カレンダーに取り込む（API は使っていない） |
| **入荷スケジュールの取り込み** | 原料・資材の入荷予定の Excel を読む |
| **在庫の検査結果** | 検査待ちの在庫の区分を変えて出荷できるようにする（固定パスワード）。WorkStation の出荷に「訂正」の印を付ける |
| **パレタイザー設定の取り込み** | パレタイザーの設定ソフトが出したテキストを読み、ロボット積み付けマスタを **全件入れ替える**。機械とはつながっていない（設定は人が行う） |

## 4. 見つかった不具合・気になる点

1. **出荷への変更の知らせが送られていない**（つながった表に使えない命令を使っていて、エラーが隠れている）。
2. **貸しパレットの在庫管理が壊れている**（表の列が変わったのにプログラムが古いまま、毎回足していく、など）。
3. 商品マスタの寸法を入れる処理が、条件によって **終わらなくなる**。
4. 包装時間の画面を閉じると、製造管理の選択の印が全部消える。
5. 一部のカレンダー画面を開くと、明日以降の自動予定を削除する。
6. パレタイザー設定の取り込みは文字の位置で読んでいるので、桁数が変わると崩れる。取り込むたびに、手で直した値が消える。
7. 自動割付が「直近の設定」ではなく、過去の任意の 1 件を使う。ニチレイ行きの判定が処理によって違う。
8. Google カレンダー用の CSV は、取り込むたびに予定が重なる。
9. 入荷スケジュールの取り込みで、年をまたぐと年がずれる。
10. 包装札の確認でキャンセルしても、印刷が止まらない。
11. 存在しない画面・帳票・表を呼んでいる箇所が多い。旧コード（倉庫 1）を使った帳票は、今はデータが出ない可能性がある。

## 5. Web 化のときに考えること

- **札・帳票の印刷**（1 パレット 1 枚、色紙・手差し、札の色・テープの種類で文字を変える）を、ブラウザからどう印刷するか（ラベルプリンターを使うか）を決める。
- パレタイザー設定は、取り込みを固定位置ではなく項目名で読むように作り直す。
- 包装予定時間の計算（平均の取り方・期間）を見直すか。
- 予定表と Google カレンダーの連携を自動にするか（API を使う）。
- 検体関係（2026年4月に廃止）、資材関係（2015年で止まっている）、本社マスタ関係、古い版・コピーの帳票は移さない。
